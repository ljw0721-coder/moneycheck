# 멀티 광고 네트워크 연결표 (ads.js의 NET 설정에 ID 입력)
| 회사 | 방식 | 이 사이트 위치 | 동시게재 | 필요한 것 |
|---|---|---|---|---|
| Google AdSense | CPC/CPM 메인 | 상단·중단·하단 기본 | 기준 네트워크 | ca-pub ID, 사이트 심사, ads.txt |
| Kakao AdFit | CPC 국내 서브 | 중단 우선 배정 | 애드센스와 병행 가능 (위치 분리) | 광고단위 ID(DAN-) 1~3개, 심사 |
| Dable | 네이티브 추천 | 하단 우선 배정 | 애드센스와 병행 가능 | 위젯 ID, 사이트 심사·트래픽 요건 |
| 쿠팡 파트너스 | 제휴 CPS | 하단 (데이블 없을 때) | 가능, 수수료 고지 문구 필수 | 파트너 ID, 추적코드 |
| 텐핑/링크프라이스 | CPA 링크형 | 본문 링크로만 삽입 | 가능 | 캠페인별 링크 (스크립트 없음) |
| 네이버 애드포스트 | - | 불가 | - | 네이버 블로그 전용이라 외부 사이트 적용 불가 |
주의: 본인 광고 클릭 금지 / 광고를 콘텐츠로 위장 금지 / 한 위치에 두 네트워크를 겹치지 말 것 / 각 회사 최신 정책 확인
